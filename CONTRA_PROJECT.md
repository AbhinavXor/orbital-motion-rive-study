# Interactive Rive Motion System — Scroll, Hover & Click

I created this interactive motion study to demonstrate how finished 2D artwork can be transformed into responsive website animation.

The graphic responds to pointer movement, scroll position and click states using a native Rive state machine.

The browser integration uses TypeScript and a small normalized input contract, making the animation easy to integrate into an existing website.

### Included

- Rive interactive animation
- Pointer / hover response
- Scroll-controlled transformation
- Click-triggered animation
- Native state machine
- Responsive behavior
- Reduced-motion support
- TypeScript integration
- Developer-ready source code
- Rive source and compiled asset
